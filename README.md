# 映画の台詞と歌詞で学ぶタミル語

映画の台詞と歌詞を題材に、タミル語の表現がどのように意味を作るかを学ぶノート集です。タミル文字が読めることを前提に、**原文・日本語訳・文法解説**を結び付けます。説明は日本語で、語幹・接辞・語順・口語表現を中心にします。

## 保存先のルール

「映画追加」「フォルダ作成」「資料保存」は、**GitHub リポジトリ `alipasa727/tamil_movie` 内**への作成・保存を意味します。映画は `movies/<映画名>-<公開年>/` にまとめます。Google Drive などの外部ストレージには、サービス名と保存先を明示した依頼がある場合だけ保存します。

保存先・アクセス範囲・最新状態の確認・GitHub への反映は [AGENTS.md](AGENTS.md) を参照してください。

## 学習の方針

原文を読み、語幹と接辞の働きを追い、訳の根拠を説明できることを目指します。場面や人物関係も合わせて読み、辞書の訳語だけでは分からない語調や使い方を考えます。

映画の会話では口語の短縮や省略を、歌詞では比喩・反復・詩的な語順を扱います。作品中の言い方と一般的な日常会話の用法を区別します。タミル文字を本文の中心に置き、ローマ字・カタカナは必要な場合の補助とします。発音は音声で確認します。

## 教材の選び方と基本構成

タミル語の原語版と吹替版を区別し、採用する音声・字幕・掲載原文の言語を確認します。日常の呼びかけ・質問・返答・依頼・否定や、格・活用・連体修飾など、学ぶポイントが明確な箇所を選びます。有名な決め台詞だけに偏らず、やり取りや人物関係の分かる表現も扱います。

台詞は一続きの発言・会話、歌詞は節・サビなどのまとまりを単位に、次の5項目をこの順に置きます。

1. **本文**：確認したタミル語原文だけを、行の区切りを保って掲載。
2. **直訳**：主語・目的語・修飾関係と接辞の働きが追える日本語訳。
3. **語彙説明**：本文の形・辞書形・品詞・意味・活用や語尾の働き。
4. **文法説明**：文の骨格から格・活用・語順・行をまたぐ関係を説明。
5. **補足**：背景、比喩、訳で補った内容、表記差、意味に関わる未確認事項。

歌詞もまとまりごとにこの構成を繰り返し、本文と訳・解説を近くに置きます。引用は学習に必要な短い抜粋にし、指示語や比喩の理解に必要な前後関係は日本語で補います。省略・繰り返しを明示し、異なる資料の文や離れた場面をつないで一つの原文を作りません。

出典・確認範囲は本文の外に簡潔にまとめます。同じ確認上の断り書きを各節に繰り返さず、意味の不明点は該当箇所の補足に記します。補足がなければ空欄にします。

## 原文と出典の扱い

**台詞・歌詞・学習用の例文は自作せず、出典を調べます。** 記憶やAIの生成文を作品の原文として掲載しません。原文が見つからない場合は掲載を見送るか、未確認事項として残します。

本編・公式字幕・公式歌詞を優先し、ユーザー提供本文・画像、台詞集・映画記事・歌詞サイトを使う場合は資料の種類を明示します。掲載本文で作品名・曲名と原文を確認できた資料から、出典付きの訳・解説を作れます。検索結果の断片や未読の画像だけでは原文確認済みとしません。ユーザー提供本文の解説と、作品への帰属の確認も区別します。

採用資料には資料名・URLまたは提供資料の識別情報、掲載箇所・抜粋範囲、確認日・方法、確認できたことと残る疑問を記録します。**掲載資料での確認と、映画本編の音声・字幕との照合は別に記録します。** 実際に照合した場合に限り、使用版、音声・字幕の言語と種類、時刻、照合範囲を残します。未確認の話者・相手・場面・タイムスタンプを推測で補いません。

資料間の綴りや省略の差は注記します。日本語字幕や自動翻訳はタミル語の原文には使わず、自動字幕も音声等との比較なしに原文確定の根拠としません。

## 日本語訳の方針

新規・改訂箇所の訳は「直訳」にまとめ、原文の構造を追える日本語にします。省略された主語・目的語や、日本語として補った語は根拠を説明します。丁寧さ・感情・人物関係に応じた言い換え、歌詞の比喩の読みは補足で説明します。複数の解釈がある場合は、文脈に合う読みと残る疑問を示します。

日本語訳は学習用に作成した訳として扱います。公式字幕や既存訳を参照した場合は、その出典を記します。

## 語彙・文法解説の方針

タミル文字を読めても文法には不慣れな人が、本文の形と意味を追える説明にします。語彙は次の表を使い、辞書形だけを並べず、本文での変化を説明します。

| 本文の形 | 辞書形 | 品詞 | 意味 | 活用・語尾の働き |
| --- | --- | --- | --- | --- |
| 本文中の語 | 辞書で確認した形 | 名詞・動詞など | この文での語義 | 語幹・接辞とその関係。未確定の分解は保留 |

文法は「誰が・何をするか」という骨格から始め、修飾・語尾・文のつながりを説明します。用語には日本語の説明を添えます。

| 項目 | 説明する内容 |
| --- | --- |
| 語幹・接辞 | 語尾が付く土台と、意味や文法上の働きを加える部分。接合時の音や綴りの変化も区別する |
| 格・所有形・後置詞 | 「〜を・〜に・〜の」など、名詞・代名詞とほかの語の関係 |
| 動詞の形 | 本文に現れる過去・現在・未来、否定、疑問、命令、条件など |
| 人称・数・性・敬意 | 誰の動作か、単数・複数、性や敬意が形にどう関わるか |
| 修飾・連体形 | どの語や節が、どの名詞を説明するか |
| 口語・書き言葉・詩的表現 | 短縮・省略・語順の違い、比喩や反復の効果。資料で確認できた対応を示す |

**語義はタミル語の辞書、文法はタミル語の文法書・教育資料・研究論文で確認します。** 共通の参照先は [タミル語の辞書・文法資料](SOURCES.md#タミル語の辞書文法資料) にまとめます。使用した節・ページ、確認方法と範囲はノートに簡潔に残します。資料の一般則、原文への当てはめ、場面からの推定を分け、根拠を確認できない分析をAIの説明だけで確認済みにしません。

口語の台詞には口語資料を使い、古い辞書・歴史文法・書き言葉の規則を現代の映画へ無条件に当てはめません。不明瞭な歌詞を無理に分解したり、もっともらしい辞書形を作ったりしません。

## 言語版と資料の区別

このリポジトリはタミル語学習用です。他言語版の構成は参考にできますが、文字や作品名の置換だけで教材・根拠を転用しません。

| 項目 | タミル語版で確認する内容 |
| --- | --- |
| 作品情報 | タミル語の原題・公開年・曲名。タミル語原語版とタミル語吹替版、他言語版を区別する |
| 台詞・歌詞 | 提供・掲載資料の言語、作品・曲への帰属、採用した範囲と表記 |
| 辞書・文法 | タミル語の語義・格・活用・構文を調べる。テルグ語等の語尾や分析は転用しない |
| 音声・字幕 | 投稿元・使用版・言語、字幕の手動／自動、自動翻訳の別 |
| 確認結果 | 本文取得・再生・原文照合・文法照合を区別。他言語版の取得成功や失敗を今回の結果にしない |

## ノートの整理と更新

映画ごとにフォルダを作り、台詞は `dialogues/dialogue.md` にまとめます。台詞の追加は同じファイルに追記し、`dialogue-001` 形式のアンカーを使います。歌詞は曲ごとに1ファイルとし、同じ曲の抜粋はそのファイルに追記します。`movie.md` は作成しません。作品一覧から各映画フォルダを開けます。

```text
movies/<映画名>-<公開年>/
├── dialogues/
│   └── dialogue.md
└── songs/
    └── Song-Title.md
```

新規作成には [台詞ひな形](movies/_template/dialogues/dialogue.md)、[歌詞ひな形](movies/_template/songs/Song-Title.md) を使います。新しい歌詞ファイルは曲名（英字の空白はハイフン）、先頭見出しも曲名だけにします。既存の番号付き歌詞ファイルは利用を続けます。

既存教材の原文・訳・解説・確認記録は保持します。従来形式の教材は対象箇所を改訂するときに5区分へ整え、別訳や根拠を形式統一だけのために削除しません。新たな資料で誤りが分かれば、根拠を示して更新します。復習問題・練習・学習進捗の記録は設けません。

作業ルールは [AGENTS](AGENTS.md)、共通資料と確認方法・既存の調査記録は [SOURCES](SOURCES.md)、個別の出典・確認範囲は各ノートにまとめます。方針変更と確認結果の更新はコミットに残します。
