# このワークスペースで作業を始める際の指示

映画・台詞・歌詞・語学ノートの依頼の対象は `/workspace/hindi_movie` です。

ファイルやフォルダを作成・編集・移動する前に、必ず次の順序で確認してください。

1. `/workspace/hindi_movie/AGENTS.md` を読む。
2. 同リポジトリの `README.md`、対象の既存ノート、必要な `movies/_template/` のひな形を読む。
3. Git ルート・作業状態・保存先を確認してから、リポジトリ内で作業する。

`/workspace` 直下を教材の保存先にしないでください。詳細なルールはリポジトリ内の `AGENTS.md` を正とします。このファイルは現在の環境内の入口であり、アプリのパーソナル指示を変更するものではありません。
